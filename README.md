# Getting-Started
This repo has example code on how to start programming in FTC Java

**This repo includes the following branches:**
- **main branch:** 2026/2027 Rev Starter Bot code 
  - single code file projects. 
  - Easier and more for teaching
  - Don't recommend programming like this going forward
- **subsystem branch:** 2026/2027 Rev Starter Bot code in the subsystem format. Recommended structure for competition and future projects

## Features:
**Three drive modes:**
- Tank drive
- Arcade drive
- Car drive

**Simple intake system**
  
  Left and right operator triggers to activate intake motor
